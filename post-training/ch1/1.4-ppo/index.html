    1.4 PPO — 经典策略优化基础¶

    论文：PPO

    Proximal Policy Optimization Algorithms (Schulman et al., 2017)
    arXiv: 1707.06347
    历史地位: 整条在线策略优化演进路线的起点，InstructGPT / ChatGPT RLHF 的核心优化器。

    核心思想¶

    在线强化学习使用旧策略 \(\pi_{\theta_{\text{old}}}\) 采样出一批轨迹后，往往要在这批数据上连续做多个 mini-batch 的梯度更新。如果步子迈得太大，新策略 \(\pi_\theta\) 偏离 \(\pi_{\theta_{\text{old}}}\) 过远，重要性采样估计的方差就会爆炸，甚至一步把模型训崩且无法恢复。

    PPO 的核心设计是：不求复杂的二阶海森矩阵约束（如 TRPO），而是直接通过一个一阶“裁剪替代目标函数（Clipped Surrogate Objective）”把单步策略变化关进信任域（Trust Region）里。

    前置铺垫：Actor-Critic 与广义优势估计（GAE）¶

    在写出 PPO 目标之前，必须先解决一个问题：奖励信号通常在整条回答写完（最后一个 token）才给出，怎么知道中间第 \(t\) 个 token 选得好不好？

    PPO 采用 Actor-Critic（演员-评论家） 架构，同时维护两个可训练网络：

    1. Actor（策略网络 \(\pi_\theta\)）：负责生成 token；
    2. Critic（价值网络 \(V_\psi(s_t)\)）：输入当前前缀状态 \(s_t = (q, o_{<t})\)，输出一个标量，用来预测“从当前前缀继续往下写完，期望最终能拿到多少总回报”。在 LLM 中，\(V_\psi\) 通常是一个与策略模型参数规模相当的 Transformer（将词表头换成标量价值头）。

    有了 Critic 的预测值，我们就能算出每一步的 TD 残差（Temporal-Difference Error，“这一步带来的惊喜”）：

    \[ \delta_t = R_t + \gamma V_\psi(s_{t+1}) - V_\psi(s_t) \]

    其中 \(R_t\) 是第 \(t\) 步的即时奖励（在 LLM 中，中间步通常只包含微小的逐 token KL 惩罚项 \(-\beta \log \frac{\pi_{\theta_{\text{old}}}(o_t\mid s_t)}{\pi_{\text{ref}}(o_t\mid s_t)}\)，最后一个 token 才加上序列总奖励 \(r_\varphi(q, o)\)），\(\gamma \in (0, 1]\) 是折扣因子（LLM 中常取 \(\gamma = 1\)）。

    GAE（Generalized Advantage Estimation，广义优势估计） 将未来各步的 TD 残差按指数衰减权重 \((\gamma\lambda)^l\) 加权求和，得到第 \(t\) 个 token 的优势估计：

    \[ \hat{A}_t^{\text{GAE}(\gamma, \lambda)} = \sum_{l=0}^{T-t-1} (\gamma \lambda)^l \, \delta_{t+l} \]

    其中 \(\lambda \in [0, 1]\) 控制偏差（Bias）与方差（Variance）的权衡：

    • 当 \(\lambda = 0\) 时，\(\hat{A}_t = R_t + \gamma V_\psi(s_{t+1}) - V_\psi(s_t)\)，完全依赖一步 Critic 预测，方差极小，但如果 Critic 没训准，偏差极大；
    • 当 \(\lambda = 1\)（且 \(\gamma = 1\)）时，中间的 \(V_\psi(s_{t+1})\) 与下一项的 \(-V_\psi(s_{t+1})\) 逐项望远镜抵消，化简为 \(\hat{A}_t = \left(\sum_{l=0}^{T-t-1} R_{t+l}\right) - V_\psi(s_t)\)，即真实累积回报减去当前基线，无偏但方差较大；
    • 实践中常取 \(\lambda = 0.95\) 在两者间折中。注意计算策略梯度时，\(\hat{A}_t\) 是作为固定标量传入的（不往 Critic 反传策略损失的梯度），Critic 自身通过拟合真实回报单独更新参数 \(\psi\)。
    📖 初学者补充：3 个 Token 手算一遍 GAE，看懂 Critic 是怎么归因的

    假设模型生成了长度 \(T=3\) 的回答并答对，即时奖励只在最后一步给出：\(R = [0, 0, 1]\)。设 \(\gamma = 1\)，终止状态价值 \(V(s_4) = 0\)，当前 Critic 对前三个状态的价值估计分别为 \(V(s_1)=0.2,\; V(s_2)=0.3,\; V(s_3)=0.4\)。

    1. 先算每一步的 TD 残差 \(\delta_t = R_t + V(s_{t+1}) - V(s_t)\)：
      • \(\delta_1 = 0 + 0.3 - 0.2 = +0.1\)（第 1 个词让预期得分从 0.2 升到 0.3，小幅加分）
      • \(\delta_2 = 0 + 0.4 - 0.3 = +0.1\)（第 2 个词让预期得分从 0.3 升到 0.4，小幅加分）
      • \(\delta_3 = 1 + 0 - 0.4 = +0.6\)（第 3 个词直接锁定胜局拿到 1 分，远超预期 0.4，大幅加分！）
    2. 对比不同 \(\lambda\) 下的优势 \(\hat{A}_t\)：
      • 若取 \(\lambda = 1\)：\(\hat{A}_3 = 0.6\)，\(\hat{A}_2 = 0.1 + 0.6 = 0.7\)，\(\hat{A}_1 = 0.1 + 0.1 + 0.6 = 0.8\)（完整继承后续真实好结果）；
      • 若取 \(\lambda = 0.5\)：\(\hat{A}_3 = 0.6\)，\(\hat{A}_2 = 0.1 + 0.5 \times 0.6 = 0.4\)，\(\hat{A}_1 = 0.1 + 0.5 \times 0.4 = 0.3\)（离终局越远，终局惊喜的传递衰减越多，越看重局部 Critic 估计）。

    这也直观暴露了隐患：如果 Critic 在长思维链早期瞎猜（比如错把 \(V(s_2)\) 估成 \(0.9\)），就会算出 \(\delta_1 = +0.7, \delta_2 = -0.5\)，给完全正确的中间步骤打出负优势！ 这正是后文 GRPO 决定砍掉 Critic、以及 VAPO 决定预训练修好 Critic 的直接动因。

    PPO 核心目标函数¶

    结合 token 级重要性采样比率 \(r_t(\theta) = \frac{\pi_\theta(o_t \mid q, o_{<t})}{\pi_{\theta_{\text{old}}}(o_t \mid q, o_{<t})}\) 与 GAE 优势 \(\hat{A}_t\)，PPO 最大化如下裁剪替代目标：

    \[ \mathcal{J}_{\text{PPO}}(\theta) = \mathbb{E}_{q \sim P(Q),\, o \sim \pi_{\theta_{\text{old}}}(\cdot\mid q)} \left[ \frac{1}{|o|} \sum_{t=1}^{|o|} \min \Big( r_t(\theta) \hat{A}_t, \; \mathrm{clip}\big(r_t(\theta),\, 1-\varepsilon,\, 1+\varepsilon\big) \hat{A}_t \Big) \right] \]

    其中裁剪超参数 \(\varepsilon\) 通常取 \(0.2\)（即允许单步概率比在 \([0.8, 1.2]\) 区间内正常推动更新）。

    双向裁剪机制解析¶

    目标中的 \(\min\!\big(r_t \hat{A}_t,\; \mathrm{clip}(r_t, 1-\varepsilon, 1+\varepsilon)\hat{A}_t\big)\) 构成了一个精巧的悲观下界（Pessimistic Lower Bound），按优势正负分四种情况运作：

    比率区间 \(\hat{A}_t > 0\)（好动作，想提高概率） \(\hat{A}_t < 0\)（坏动作，想压低概率）
    \(r_t > 1 + \varepsilon\)（新概率已大幅高于旧概率） 触发裁剪：取常数 \((1+\varepsilon)\hat{A}_t\)，梯度归零，防止过度拔高单个词 不裁剪：\(\hat{A}_t < 0\) 时 \(r_t \hat{A}_t\) 更负，min 选中未裁剪项，继续把错误高概率拉回来
    \(r_t < 1 - \varepsilon\)（新概率已大幅低于旧概率） 不裁剪：min 选中 \(r_t \hat{A}_t\)，允许把过低的好动作概率拉升回来 触发裁剪：取常数 \((1-\varepsilon)\hat{A}_t\)，梯度归零，防止把词表概率一脚踩塌
    \(1-\varepsilon \le r_t \le 1+\varepsilon\)（信任域内） 正常按 \(r_t \hat{A}_t\) 更新 正常按 \(r_t \hat{A}_t\) 更新

    PPO 在大规模 LLM 场景中的三大痛点¶

    PPO 最初为连续控制和 Atari 游戏（动作空间极小、回合较短、奖励密集）设计，迁移到百亿～千亿参数 LLM 的长链推理后，暴露出三个沉重负担：

    1. 四模型常驻显存开销极高：训练时集群必须同时承载 Actor (\(\pi_\theta\), 训练) + Critic (\(V_\psi\), 训练) + Reference (\(\pi_{\text{ref}}\), 冻结前向) + Reward Model (\(r_\varphi\), 冻结前向) 四个大体量网络，显存与跨卡通信成本高昂；
    2. 稀疏奖励下 Critic 冷启动极难训练：LLM 往往生成几千个 token 才在末尾拿到一个对错分数，Critic 在训练初期对前中部 token 的价值预测几乎全是噪声；
    3. 长思维链（Long CoT）中价值误差累积：当推理长度扩展到 16K～64K token 时，Critic 的微小偏差会通过 TD 递推污染整条链的优势方向。

    这三个痛点，直接催生了下一节消去 Critic 的 GRPO，以及后来在 1.7 节中专门修复 Critic 的 VAPO。
