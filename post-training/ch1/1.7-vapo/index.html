    1.7 VAPO — Value-Based 路线的回归与修正¶

    本节摘要

    VAPO 融合了 PPO 的 Actor-Critic 细粒度归因路线与 GRPO/DAPO 的工程改进，针对 Critic 在长思维链中失效的根因提出 Value Pretraining、Decoupled GAE 和 Length-Adaptive GAE 三项修复技术，并引入正样本模仿损失，在 Qwen2.5-32B 上将 AIME 2024 从原始 PPO 的 5 分、DAPO 的 50 分进一步推高至 60.4 分。

    论文：VAPO

    VAPO: Efficient and Reliable Reinforcement Learning for LLM Reasoning with Verifiable Rewards (ByteDance Seed, 2025)
    arXiv: 2504.05118
    历史地位: 跨分支融合代表作（PPO + GRPO + DAPO），系统证明了在显存允许的规模下，修好 Critic 后的 Value-Based 路线优于 Value-Free 路线。

    核心论点¶

    GRPO 与 DAPO 等 Value-Free 算法把整条回答的标量奖励平均分摊给序列里的每一个 token：即便一条 10,000 token 的推导前 8,000 token 思路完全正确、只因最后一步算错了一位数而得 \(-1\) 分，前 8,000 个好 token 也会被一并惩罚。

    VAPO 的核心判断是：Value-Free 在短任务上够用，但在超长 CoT 推理中，Critic 提供的逐 token 细粒度信用分配（Credit Assignment）具有不可替代的上限优势——此前 PPO 在长链推理上失败，不是 Actor-Critic 范式不行，而是 Critic 没修好。

    核心公式¶

    VAPO 总损失函数（在最小化视角下写作策略损失加辅助负对数似然）：

    \[ \mathcal{L}_{\text{VAPO}}(\theta) = \mathcal{L}_{\text{PPO}}(\theta) + \mu \cdot \mathcal{L}_{\text{NLL}}(\theta) \qquad (\mu = 0.1) \]

    其中策略部分 \(\mathcal{L}_{\text{PPO}}(\theta)\) 继承了 DAPO 的 Clip-Higher（非对称裁剪）、Token-Level Loss（全局词元归一化） 与 Dynamic Sampling，但将每个位置的优势 \(\hat{A}_t\) 重新交由 Critic 网络配合改进后的 GAE 计算。

    正样本模仿学习损失（Positive-Example LM Loss）：

    \[ \mathcal{L}_{\text{NLL}}(\theta) = -\frac{1}{\sum_{o_i \in \mathcal{T}} |o_i|} \sum_{o_i \in \mathcal{T}} \sum_{t=1}^{|o_i|} \log \pi_\theta(o_{i,t} \mid q, o_{i,<t}) \]

    其中 \(\mathcal{T}\) 是当前训练 batch 中答案核验正确的样本集合。在训练初期或面对难题时，采样到的正确轨迹非常珍贵；直接对正确轨迹叠加小权重的极大似然损失（即“自我模仿学习”），能够提高正样本利用率并稳定策略分布。消融显示去掉该项会使 AIME 得分从 60.4 降至 54（\(-6.4\) 分）。

    三大 Critic 修复技术¶

    为什么原始 PPO 在长 CoT 上只得 5 分？VAPO 定位了三个导致 Critic 崩溃的环节并逐一修复：

    修复技术 具体做法 移除后 AIME 得分
    1. Value Pretraining（价值预训练） 正式 RL 启动前，先冻结策略 \(\pi_{\theta_0}\) 采样轨迹，用真实终局回报（Monte Carlo Return）单独训练 Critic 约 50 步，待价值损失与解释方差稳定后再开启联合 RL 11（暴跌 \(-49.4\)，直接崩溃）
    2. Decoupled GAE（解耦 GAE） 更新 Critic 回归目标时使用 \(\lambda_{\text{critic}} = 1.0\)（无偏蒙特卡洛目标），计算策略更新优势时使用更小的 \(\lambda_{\text{policy}}\)（降低策略梯度方差） 33（下降 \(-27.4\)）
    3. Length-Adaptive GAE（长度自适应 GAE） 令 \(\lambda_{\text{policy}} = 1 - \dfrac{1}{\alpha \cdot l}\)（\(l\) 为序列长度，超参 \(\alpha = 0.05\)），使 TD 残差的有效传播视野与序列长度成正比 45（下降 \(-15.4\)）
    📖 初学者补充：为什么 Value Pretraining 和 Length-Adaptive GAE 如此关键？
    1. 什么是 Monte Carlo (MC) 回报，为什么不能直接拿 RM 或随机头冷启动 Critic？
      • 在没有中间奖励且 \(\gamma=1\) 的 RLVR 中，一条完整回答若最终得分为 \(R \in \{+1, -1\}\)，那么这条轨迹上每一个位置 \(t\) 的真实 MC 回报就是 \(G_t = R\)（直接看终局真值，不依赖任何估计）。
      • 以往 RLHF 常从奖励模型（RM）初始化 Critic，但 RM 只在句末 <EOS> 位置受过打分训练，对句子前中部的 token 输出有严重的初始化偏置；而在 RLVR 中没有 RM，随机初始化的价值头输出的更是纯随机噪声。如果不先用 MC 回报把 Critic 预训练准，RL 第一步算出的 GAE 优势方向完全随机，几步就会把策略网络带崩。
    2. 为什么固定 \(\lambda = 0.95\) 在上万 token 的长思维链上会失灵？
      • 回看 1.4 节 GAE 公式 \(\hat{A}_t = \sum_{l=0}^{T-t-1} \lambda^l \delta_{t+l}\)。当固定 \(\lambda = 0.95\) 时，终局第 \(T\) 步的真实奖励信号往前传 100 个 token 后，权重只剩 \(0.95^{100} \approx 0.0059\)；往前传 500 个 token 后权重是 \(0.95^{500} \approx 7 \times 10^{-12} \approx 0\)！这意味着一条 8,000 token 的回答，前 7,500 个 token 根本收不到终局对错的直接反馈，全靠有误差的 Critic 自举（Bootstrapping）。
      • 改用 Length-Adaptive GAE \(\lambda_{\text{policy}} = 1 - \frac{1}{\alpha l}\) 后：若序列长 \(l=100\)，\(\lambda = 1 - \frac{1}{5} = 0.80\)；若序列长 \(l=4,000\)，\(\lambda = 1 - \frac{1}{200} = 0.995\)（此时跨越 \(4,000\) 步的衰减与短序列跨越 \(100\) 步同量级，均为 \(e^{-1/\alpha}\)），确保任意长度的推理链都能把终局信号顺畅传回起点。

    七大组件的技术来源汇总¶

    组件模块 技术来源 继承 / 原创定位
    Value Model + GAE 框架 PPO 继承自 Actor-Critic 路线
    Group Sampling（同题多采样增强对比） GRPO 继承自组采样设计
    Clip-Higher、Token-Level Loss、Dynamic Sampling DAPO 继承自 DAPO 工程改进
    Value Pretraining、Decoupled GAE、Length-Adaptive GAE、Positive-Example LM Loss VAPO 针对长 CoT Actor-Critic 的核心原创
