    1.12 演进逻辑总结¶

    将本章介绍的在线策略优化算法串联起来，每一个新算法都不是凭空设计的变体，而是精准针对上一代算法在大规模推理或 MoE 训练中暴露出的某个具体痛点：

    flowchart TD
    PPO(["PPO (RLHF)<br/>Actor-Critic + 对称硬裁剪"]) -->|"4 模型显存过高<br/>稀疏奖励下 Critic 难训"| GRPO["GRPO (RLVR 奠基)<br/>消除 Critic，采用组内相对优势<br/>配合可验证规则奖励"]

    GRPO -->|"对称裁剪引发熵坍塌<br/>全对/全错组零梯度空转<br/>样本平均稀释长链梯度"| DAPO["DAPO<br/>Clip-Higher + 动态采样<br/>+ 全局 Token 归一化 + 软超长惩罚"]

    DAPO -->|"多步更新中越界即断梯度<br/>低概率反思词仍学不充分"| CISPO["CISPO<br/>在 sg(·) 内裁剪 Token IS 权重<br/>保留全部有效 token 的 log π 梯度"]

    GRPO -.->|"MoE 离散路由跳变<br/>冲击 Token IS"| RR["Routing Replay (R2 / R3)<br/>工程侧锁死训练与采样路由"]
    RR -.->|"跨引擎侵入与通信复杂"| GSPO

    DAPO -->|"序列奖励 vs Token IS 错配<br/>MoE 路由噪声累积崩溃"| GSPO["GSPO<br/>序列级几何平均 IS 比率<br/>原生稳住 MoE 训练"]

    GSPO -->|"硬裁剪边界梯度跳变<br/>单点异常可致整句截断"| SAPO(["SAPO<br/>非对称温度 Sigmoid 软门控<br/>连续信任域 + 序列级自洽"])
    CISPO -->|"追求无硬边界平滑衰减"| SAPO

    演进图中的三条技术主线¶

    三条主线的分野与汇流

    1. Token 级信任域精炼线（GRPO → DAPO → CISPO → SAPO）：始终保持逐 token 计算比率，依次解决探索空间不足（Clip-Higher）、越界梯度消失（CISPO 裁权重留梯度）以及裁剪边界不连续（SAPO 软门控）；
    2. MoE 粒度对齐线（GRPO → Routing Replay / GSPO → SAPO）：针对 MoE 专家路由切换对逐 token 比率的噪声污染，一条路在工程侧锁死专家选择（Keep Routing / R3），另一条路在算法侧升维到序列几何平均（GSPO），最终与第一条线在 SAPO 处汇合（Token 级软门控在小步长下自然展现序列级平滑性，同时保留单点异常隔离能力）；
    3. 精细价值归因线（PPO → VAPO）：在显存允许的模型规模（如 32B～200B MoE）下，通过 Value Pretraining 与长度自适应 GAE 修好 Critic，夺回长思维链内部的逐词元信用分配精度优势。
