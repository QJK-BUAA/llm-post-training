# 1.4 PPO

论文：*Proximal Policy Optimization Algorithms*（Schulman et al., 2017）。InstructGPT 用它把奖励模型的分数变成策略更新。

PPO 的约束很具体：用旧策略采来的数据更新新策略时，单步不要走得太远。实现这个约束的是裁剪后的替代目标。

## 优势和价值函数

策略 \(\pi_\theta\) 在语言模型里就是「给定题目和已生成 token，下一个 token 的分布」。

一次更新用的回答来自 \(\pi_{\theta_{\mathrm{old}}}\)。新策略的概率和旧策略不同，所以每个 token 乘重要性比率

$$
r_t(\theta)
= \frac{\pi_\theta(o_t \mid q, o_{<t})}{\pi_{\theta_{\mathrm{old}}}(o_t \mid q, o_{<t})}
$$

**优势** \(\hat A_t\) 表示这个 token 比基线好多少。大于 0 就提高它的概率，小于 0 就降低。

基线来自**价值函数** \(V_\psi(s)\)。它估计的是：从当前前缀出发，按策略继续写下去，期望还能拿到的累积奖励。LLM 的奖励常常只在最后一个 token 给出，前面的 token 没有自己的分数，所以要靠 \(V_\psi\) 把终局奖励分到前缀上。\(V_\psi\) 是另一个网络，称为 Critic。策略网络是 Actor。

一步的 TD 误差是「这一步实际看到的」减去「价值函数原来的估计」：

$$
\delta_l = R_l + \gamma V_\psi(s_{l+1}) - V_\psi(s_l)
$$

\(R_l\) 是这一 token 的即时奖励，终局之外通常是 0。\(\gamma \in (0,1]\) 是未来奖励的折扣。GAE 把后面多步的 TD 误差加起来：

$$
\hat A_t^{\mathrm{GAE}(\gamma,\lambda)}
= \sum_{l=0}^{T-t-1} (\gamma \lambda)^l \, \delta_{t+l}
$$

\(\lambda \in [0,1]\) 控制看得多远。\(\lambda = 1\) 时几乎使用整段真实回报，偏差小、方差大。\(\lambda\) 更小则更依赖 \(V_\psi\)，方差小、偏差大。长思维链上，Critic 只要估偏，误差会沿这条和一直传。

## 裁剪目标

$$
\mathcal{J}_{\mathrm{PPO}}(\theta)
= \mathbb{E}
\left[
\frac{1}{|o|}
\sum_{t=1}^{|o|}
\min \Big(
r_t(\theta)\, \hat A_t,\;
\mathrm{clip}(r_t(\theta), 1-\varepsilon, 1+\varepsilon)\, \hat A_t
\Big)
\right]
$$

\(\varepsilon\) 常取 0.2。期望里的样本来自旧策略。`min` 的效果取决于优势的符号：

| | 优势为正 | 优势为负 |
| --- | --- | --- |
| \(r_t > 1+\varepsilon\) | 停在 \(1+\varepsilon\)，不再继续加大 | 不裁，允许继续减小 |
| \(r_t < 1-\varepsilon\) | 不裁，允许继续加大 | 停在 \(1-\varepsilon\)，不再继续压低 |

被选中的那一侧如果是常数 \((1\pm\varepsilon)\hat A_t\)，它对 \(\theta\) 的梯度就是 0。另一侧梯度还在。

## 放到 LLM 上的三个负担

1. 同时常驻四个模型：策略、参考模型、奖励模型、Critic。Critic 往往和策略同规模。
2. 奖励稀疏。Critic 却要在每个 token 给出价值。
3. 思维链一长，价值误差会累积。GRPO 因此去掉 Critic，改用同题一组回答的相对分数。奖励模型去不去掉，是另一件独立的事。
