# 1.8 CISPO

论文：*MiniMax-M1*（[arXiv:2506.13585](https://arxiv.org/abs/2506.13585)）。全称是 Clipped IS-weight Policy Optimization。

它仍是 **token 级**算法。改变的是裁剪对象：PPO 和 GRPO 裁的是目标函数，越界后梯度为 0；CISPO 把比率裁成一个常数系数，再乘到 \(\log \pi_\theta\) 上，对数概率的梯度保留。

## 为什么要改裁剪对象

MiniMax 的训练对一批 rollout 做多步更新。论文的设置里，每批采样之后有多轮梯度步，数据相对最新策略变成 off-policy。转折词的旧概率低，比率很快超过上界。GRPO 会在第一轮就把这个 token 的梯度掩掉，后面的轮次也不再学它。

带重要性比率的 REINFORCE 可以写成

$$
\mathcal{J}
= \mathbb{E}
\left[
\sum_t
\mathrm{sg}\big(r_t(\theta)\big)\,
\hat A_t\,
\log \pi_\theta(o_t \mid q, o_{<t})
\right]
$$

\(\mathrm{sg}\) 是 stop-gradient：前向还用这个数，反传时把它当常数。比率不再给 \(\theta\) 贡献梯度，梯度只从 \(\log \pi_\theta\) 流出。CISPO 把送进 \(\mathrm{sg}\) 的比率先裁剪，并采用 GRPO 的组优势和 DAPO 的 token 级归一化：

$$
\mathcal{J}_{\mathrm{CISPO}}(\theta)
= \mathbb{E}
\left[
\frac{1}{\sum_i |o_i|}
\sum_i \sum_t
\mathrm{sg}\big(\hat r_{i,t}(\theta)\big)\,
\hat A_{i,t}\,
\log \pi_\theta(o_{i,t} \mid q, o_{i,<t})
\right]
$$

$$
\hat r_{i,t}
= \mathrm{clip}\big(r_{i,t},\, 1-\varepsilon^{\mathrm{IS}}_{\mathrm{low}},\, 1+\varepsilon^{\mathrm{IS}}_{\mathrm{high}}\big)
$$

M1 的实验把下界放得很松，实际只调节上界。无下界时，比率很小的 token 仍按真实比率衰减，而不是被抬到一个地板上。

## 和 PPO 的梯度差在哪里

| | 比率落在界内 | 优势为正且比率超过上界 |
| --- | --- | --- |
| PPO / GRPO | \(r \hat A \nabla \log \pi\) | 0 |
| CISPO | \(r \hat A \nabla \log \pi\) | \((1+\varepsilon_{\mathrm{high}})\hat A \nabla \log \pi\) |

界内两者一致，因为 \(\nabla r = r \nabla \log \pi\)。越界后 PPO 丢掉这个 token，CISPO 把系数封顶，对数概率的梯度还在。

优势为 0 时两种算法的梯度都是 0。全对或全错的题不会因为换成 CISPO 就产生方向，M1 因此同时使用了 DAPO 的动态采样和长度惩罚，并且不加 KL。

在 Qwen2.5-32B 的对照实验里，同样的数学数据上，CISPO 用大约一半的训练步数达到 DAPO 的表现。这是步数效率，不是「改成序列几何平均所以不用保存每个 token 的比率」。序列几何平均是下一节的 GSPO。
