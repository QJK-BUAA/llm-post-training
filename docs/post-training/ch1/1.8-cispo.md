# 1.8 CISPO — 裁剪 IS 权重而非目标函数

!!! abstract "本节摘要"
    CISPO（Clipped IS-weight Policy Optimization）诊断出 PPO/GRPO/DAPO 硬裁剪目标函数会在多轮 mini-batch 更新中过早丢弃低概率关键推理词的梯度。通过改为**在停止梯度算子 $\mathrm{sg}(\cdot)$ 内裁剪逐 token 的重要性采样权重**，CISPO 既封顶了离群更新幅度，又让所有优势非零的 token 持续保留有效策略梯度，在同基座对照实验中仅用 DAPO 一半的训练步数即追平性能。

!!! abstract "论文：CISPO"
    *MiniMax-M1: Scaling Test-Time Compute Efficiently with Lightning Attention* (MiniMax, 2025)  
    **arXiv**: [2506.13585](https://arxiv.org/abs/2506.13585)  
    **历史地位**: 提出“裁剪重要性采样权重系数而非裁剪替代目标”的 Token 级策略梯度范式。

## 核心问题：多轮 Off-Policy 更新下的“分岔词出局”

在长思维链推理中，决定模型能否跳出死胡同的往往是少数几个**推理分岔词（Fork Tokens）**，例如 `"Wait"`、`"However"`、`"Recheck"`、`"Alternatively"`。

这些词在初始模型 $\pi_{\theta_{\text{old}}}$ 下的生成概率很低，一旦某次探索用到了它们并成功答对（$\hat{A}_{i,t} > 0$），它们的新旧概率比 $r_{i,t}(\theta) = \frac{\pi_\theta}{\pi_{\theta_{\text{old}}}}$ 会迅速增大。在工业级 RL 训练中，每采样一大批数据通常会切分成多个 mini-batch 做多步更新（例如 MiniMax 的设置是每批 rollout 做 16 轮更新）：

- 在 PPO / GRPO / DAPO 的 `min(r·A, clip(r)·A)` 硬裁剪下，这些分岔词往往在**第 1 轮更新后比率就突破 $1+\varepsilon_{\text{high}}$ 被直接裁掉（梯度归零）**，在剩下的 15 轮更新中彻底失去学习信号；
- 即便像 DAPO 那样把 $\varepsilon_{\text{high}}$ 从 $0.2$ 放宽到 $0.28$，也只是稍微推迟了被踢出局的时刻，并未消除“越界即断梯度”的机制。

## 前置概念：什么是 $\mathrm{sg}(\cdot)$（Stop-Gradient）与带权 REINFORCE？

在看 CISPO 公式之前，先明确算子 $\mathrm{sg}(\cdot)$（在 PyTorch 代码中即 `tensor.detach()`）的作用：

- **前向计算时**：$\mathrm{sg}(u)$ 的数值完全等于 $u$ 本身；
- **反向求导时**：把 $\mathrm{sg}(u)$ 当作与参数 $\theta$ 无关的**常数标量**，$\nabla_\theta \mathrm{sg}(u) = \mathbf{0}$，梯度不穿过它回传。

由此，经典的异策略校正 **REINFORCE 策略梯度** 可以等价写成一个极简的替代目标函数：

$$
\mathcal{J}_{\text{REINFORCE-IS}}(\theta) = \mathbb{E}_{q,\, o \sim \pi_{\theta_{\text{old}}}} \left[ \frac{1}{|o|} \sum_{t=1}^{|o|} \mathrm{sg}\!\big(r_t(\theta)\big) \cdot \hat{A}_t \cdot \log \pi_\theta(o_t \mid q, o_{<t}) \right]
$$

你可以立刻验证它的梯度：因为 $\mathrm{sg}(r_t)$ 和 $\hat{A}_t$ 在求导时都是常数，对 $\theta$ 求导只作用在末尾的 $\log \pi_\theta$ 上，恰好给出无偏异策略梯度 $r_t(\theta)\hat{A}_t \nabla_\theta \log \pi_\theta$——这与 PPO 在未裁剪区间内对 $r_t(\theta)\hat{A}_t$ 求导的结果完全相同（因为 $\nabla_\theta r_t = r_t \nabla_\theta \log \pi_\theta$）！

## CISPO 核心公式

看清了上面这一步，CISPO 的设计就水到渠成了：**不要去裁整个目标项，而是直接在上面那个 $\mathrm{sg}(\cdot)$ 里面把重要性权重 $r_{i,t}(\theta)$ 裁剪封顶**，同时结合 GRPO 的组相对优势与 DAPO 的全局 Token 归一化：

$$
\mathcal{J}_{\text{CISPO}}(\theta) = \mathbb{E}_{(q,a)\sim\mathcal{D},\, \{o_i\}_{i=1}^G \sim \pi_{\theta_{\text{old}}}(\cdot\mid q)} \left[ \frac{1}{\sum_{i=1}^{G}|o_i|} \sum_{i=1}^{G} \sum_{t=1}^{|o_i|} \mathrm{sg}\!\left(\hat{r}_{i,t}(\theta)\right) \cdot \hat{A}_{i,t} \cdot \log \pi_\theta(o_{i,t} \mid q, o_{i,<t}) \right]
$$

其中裁剪后的 **Token 级重要性权重** 为：

$$
\hat{r}_{i,t}(\theta) = \mathrm{clip}\!\left(r_{i,t}(\theta),\; 1 - \varepsilon_{\text{low}}^{\text{IS}},\; 1 + \varepsilon_{\text{high}}^{\text{IS}}\right)
$$

!!! tip "MiniMax-M1 的关键实验细节：单侧封顶（只设上界）"
    MiniMax-M1 论文 §3.1 指出，在实际训练中他们将 $\varepsilon_{\text{low}}^{\text{IS}}$ 设得很大（相当于**取消下界截断，只调节上界 $\varepsilon_{\text{high}}^{\text{IS}}$**），并同样移除了 KL 惩罚、沿用了动态采样与长度惩罚。原因很直观：当某个旧 token 的概率比 $r_{i,t} \to 0$ 时，自然衰减权重本身就是安全的；如果强行给它设一个正的下界地板（如 $0.8$），反而会在异策略步数较多时放大已过时 token 的更新偏差。

## PPO / GRPO vs CISPO 梯度行为对比

对任意优势非零（$\hat{A}_{i,t} \neq 0$）的单个 token 求梯度：

$$
\nabla_\theta \mathcal{J}_{\text{CISPO}} \;\propto\; \sum_{i,t} \underbrace{\mathrm{sg}\big(\hat{r}_{i,t}(\theta)\big)}_{\text{封顶后的正标量系数}} \cdot \hat{A}_{i,t} \cdot \underbrace{\nabla_\theta \log \pi_\theta(o_{i,t} \mid q, o_{i,<t})}_{\text{始终可微、梯度保留}}
$$

| 算法 | 裁剪作用对象 | 当 $r_{i,t}$ 在界内时单 token 梯度 | 当 $\hat{A}_{i,t}>0$ 且 $r_{i,t} > 1+\varepsilon_{\text{high}}$ 时 |
|------|-------------|-----------------------------------|------------------------------------------------------------------|
| **PPO / GRPO / DAPO** | 替代目标 $r_{i,t}\hat{A}_{i,t}$ | $r_{i,t}\hat{A}_{i,t}\nabla_\theta \log \pi_\theta$ | **$\mathbf{0}$（该 token 被踢出后续更新）** |
| **CISPO** | $\mathrm{sg}(\cdot)$ 内的权重 $r_{i,t}$ | $r_{i,t}\hat{A}_{i,t}\nabla_\theta \log \pi_\theta$ | **$(1+\varepsilon_{\text{high}}^{\text{IS}})\hat{A}_{i,t}\nabla_\theta \log \pi_\theta$（权重封顶，继续学习）** |

??? info "📖 PyTorch 三行代码对比 PPO 裁剪与 CISPO"
    ```python
    # ratio: exp(new_logp - old_logp), 形状 [B, T]
    # 1. PPO / GRPO / DAPO: 越界后 clamp 分支无梯度，min 选中它时梯度直接变 0
    ppo_loss = -torch.min(ratio * adv, ratio.clamp(1 - eps_low, 1 + eps_high) * adv)

    # 2. CISPO: 权重 clamp 后 detach() 作常数系数，梯度永远经由 new_logp 正常回传
    clipped_weight = ratio.clamp(max=1 + eps_high_is).detach()
    cispo_loss = -(clipped_weight * adv * new_logp)
    ```
    注意：当全组全对或全错导致 $\hat{A}_{i,t} = 0$ 时，任何策略梯度算法在该组上的梯度自然为 $0$，因此 CISPO 依然配合 Dynamic Sampling 过滤零优势组。虽然截断 IS 权重会引入轻微有偏性，但换来了全序列稀有推理 token 梯度的完整保留与低方差，在 Qwen2.5-32B 零起点 RL 对照实验中仅用 **50% 训练步数**就达到了 DAPO 的水平（实现约 **2× 训练步数加速**）。
