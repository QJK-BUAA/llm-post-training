# 1.3 DPO — 离线偏好优化

!!! abstract "论文：DPO"
    *Direct Preference Optimization: Your Language Model is Secretly a Reward Model* (Rafailov et al., 2023)  
    **arXiv**: [2305.18290](https://arxiv.org/abs/2305.18290)  
    **核心地位**: 绕开显式奖励模型与在线采样，直接从离线成对偏好数据更新策略模型的代表性算法。

DPO 是 RLHF 范式下最重要的简化变体。它的核心洞察正如论文副标题所言：**语言模型本身就隐式定义了一个奖励模型**——因此无需先训练独立的 $r_\varphi$、再跑复杂的 PPO，一步分类损失就能求解相同的数学目标。

## 从 RLHF 目标到 DPO 损失的三步推导

为什么 DPO 可以把奖励模型整个消掉？只需三步代数变形就能看清全貌：

**第一步：写出 KL 约束下 RL 目标的闭式最优解**

回顾 1.2 节中带 KL 正则的策略优化目标：

$$
\max_{\pi} \; \mathbb{E}_{y \sim \pi(\cdot \mid x)} \left[ r(x, y) - \beta \log \frac{\pi(y \mid x)}{\pi_{\text{ref}}(y \mid x)} \right]
$$

固定提示 $x$ 与任意奖励函数 $r(x, y)$，利用 Gibbs 不等式（KL 散度非负性）可以直接解出使上式最大化的唯一最优策略 $\pi^*(y \mid x)$：

$$
\pi^*(y \mid x) = \frac{1}{Z(x)} \, \pi_{\text{ref}}(y \mid x) \exp\!\left( \frac{1}{\beta} r(x, y) \right)
$$

其中 $Z(x) = \sum_{y} \pi_{\text{ref}}(y \mid x) \exp\!\left(\frac{1}{\beta} r(x, y)\right)$ 是归一化配分函数（保证所有可能回答的概率之和为 $1$）。因为要对所有可能的文本序列 $y$ 求和，$Z(x)$ 在计算上是完全无法直接求出的。

**第二步：用最优策略反解出奖励函数 $r(x, y)$**

将上式两边取对数并移项，可以把奖励 $r(x, y)$ 反过来表示成策略与参考模型的对数概率比：

$$
r(x, y) = \beta \log \frac{\pi^*(y \mid x)}{\pi_{\text{ref}}(y \mid x)} + \beta \log Z(x)
$$

**第三步：代入 Bradley-Terry 偏好模型，配分函数 $\log Z(x)$ 恰好抵消**

在 1.2 节的 Bradley-Terry 偏好概率 $P(y_w \succ y_l \mid x) = \sigma\!\big(r(x, y_w) - r(x, y_l)\big)$ 中，决定胜负的只有**同一提示 $x$ 下两条回答的奖励差**。把第二步的表达式代入，只依赖 $x$ 而不依赖具体回答 $y$ 的难算项 $\beta \log Z(x)$ 在一减之下彻底消失：

$$
r(x, y_w) - r(x, y_l) = \beta \log \frac{\pi^*(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi^*(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)}
$$

用参数化策略 $\pi_\theta$ 直接去拟合这一最优偏好概率，最大化对数似然，就得到了 **DPO 损失函数**：

$$
\mathcal{L}_{\text{DPO}}(\theta) = -\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}_{\text{pref}}} \left[ \log \sigma\!\left( \beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)} \right) \right]
$$

??? info "📖 初学者补充：从梯度角度看 DPO 在做什么？"
    令隐式奖励差 $\hat{\Delta}_\theta = \beta \log \frac{\pi_\theta(y_w\mid x)}{\pi_{\text{ref}}(y_w\mid x)} - \beta \log \frac{\pi_\theta(y_l\mid x)}{\pi_{\text{ref}}(y_l\mid x)}$，对 $\theta$ 求导可得：

    $$
    \nabla_\theta \mathcal{L}_{\text{DPO}}(\theta) = -\beta \, \mathbb{E}_{(x, y_w, y_l)} \Big[ \underbrace{\sigma(-\hat{\Delta}_\theta)}_{\text{判错程度权重}} \cdot \big( \underbrace{\nabla_\theta \log \pi_\theta(y_w \mid x)}_{\text{拉高好回答概率}} - \underbrace{\nabla_\theta \log \pi_\theta(y_l \mid x)}_{\text{压低坏回答概率}} \big) \Big]
    $$

    它的物理意义非常直观：同时提高胜出回答 $y_w$ 的对数概率、降低落败回答 $y_l$ 的对数概率；而且前面乘了一个自适应权重 $\sigma(-\hat{\Delta}_\theta)$——如果当前模型还没分清好坏（给坏回答赋了相对偏高的概率，$\hat{\Delta}_\theta < 0$），权重就接近 $1$，重点更新；如果已经拉开了足够差距，权重就趋近于 $0$，防止过度推高或压低。

## 优势与离线局限性

- **核心优点**：不需要训练和驻留奖励模型，不需要在线 Rollout 采样，也没有 Critic 网络；训练开销和稳定性几乎与 SFT 一样友好。
- **核心局限（离线分布偏移）**：标准 DPO 的偏好对 $(y_w, y_l)$ 是事先离线收集好的（没有 $\pi_{\theta_{\text{old}}}$ 在线交互）。随着 $\pi_\theta$ 不断更新，模型自己真正容易犯的新错误并不在静态数据集里；同时，同时压低 $y_l$ 可能意外把概率质量推向词表外未曾见过的分布区域。为此，工业界常采用**多轮迭代在线采样 DPO（Iterative / Online DPO）**来缓解偏移。

## DPO 在现代工业流水线中的定位

经过两年的大规模工业验证，DPO 的适用边界已经非常清晰：

- **通用对话与风格对齐**：在调整语气、简洁度、安全性以及消化现成偏好数据时极具性价比。例如 LLaMA 3.1 曾以多轮 DPO 作为主力对齐手段，Qwen2.5 与 MiniMax-01 也用离线 DPO 消化十万级多维偏好对，再接在线 RL。
- **复杂推理与多步交互任务**：在竞赛数学、代码生成与 Agent 工具使用上，**在线强化学习（GRPO / DAPO / VAPO / CISPO / GSPO）显著优于离线 DPO**——因为推理能力需要模型在自身当前生成分布上不断试错、发现新路径并获得即时反馈。
- **最新演进位置**：Meta 在 LLaMA 4 中已将 DPO 从核心能力引擎调整为轻量的后处理步骤，而将重头算力交给了 Online RL。

!!! tip "延伸阅读：DPO 家族常见变体"
    围绕 DPO 的参考模型开销、长度偏差与成对数据要求，后续衍生出了若干常见变体（详见综述 [arXiv:2503.06072](https://arxiv.org/abs/2503.06072)）：

    - **IPO**（Identity Preference Optimization）：将 $\log \sigma$ 换为平方损失回归固定边界，减轻确定性偏好下的过拟合；
    - **KTO**（Kahneman-Tversky Optimization）：无需成对比较 $(y_w, y_l)$，只需单条回答的二元“好/坏”标签即可训练；
    - **ORPO / SimPO**：消除了参考模型 $\pi_{\text{ref}}$，其中 SimPO 直接用长度归一化的平均对数似然加目标间隔（Margin）构造隐式奖励，省去一份模型显存。
