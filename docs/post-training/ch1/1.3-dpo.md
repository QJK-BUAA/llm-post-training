# 1.3 DPO

论文：*Direct Preference Optimization: Your Language Model is Secretly a Reward Model*（Rafailov et al., 2023，[arXiv:2305.18290](https://arxiv.org/abs/2305.18290)）。

DPO 仍然使用偏好对，但不再单独训练奖励模型，也不跑在线采样。它把 1.2 的 KL 正则目标解出来，再代回 Bradley-Terry。

## 它为什么能去掉奖励模型

在 KL 惩罚下，最优策略和奖励之间有闭式关系：奖励可以用当前策略和参考模型的对数概率差表示，再加一个只依赖提示的项。这个只依赖提示的项在比较两条回答时会消掉。于是 Bradley-Terry 里的奖励差变成：

$$
r(x, y_w) - r(x, y_l)
= \beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\mathrm{ref}}(y_w \mid x)}
- \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\mathrm{ref}}(y_l \mid x)}
$$

让模型提高「\(y_w\) 胜过 \(y_l\)」的概率，就得到损失：

$$
\mathcal{L}_{\mathrm{DPO}}(\theta)
= -\mathbb{E}_{(x, y_w, y_l)}
\left[
\log \sigma \left(
\beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\mathrm{ref}}(y_w \mid x)}
- \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\mathrm{ref}}(y_l \mid x)}
\right)
\right]
$$

数据是事先收集好的。训练时不再从 \(\pi_\theta\) 采样，所以没有旧策略 \(\pi_{\theta_{\mathrm{old}}}\)。参考模型仍然在，用来保持和 SFT 起点的距离。

## 它适合放在哪里

DPO 不需要奖励模型和在线采样，训练稳定。偏好数据一旦过时，策略已经走到数据分布外面，更新方向就会偏。这是离线方法的分布偏移。

工业报告里的位置大致是：

- 通用对齐上，LLaMA 3.1 的对比认为 DPO 可以优于他们实现的 PPO。DeepSeek 和字节的推理实验把主要提升放在在线 RL 上，两边比的不是同一类任务。
- 竞赛数学和代码上，GRPO、DAPO、VAPO 这一路明显高于 DPO。
- LLaMA 4 把 DPO 从主力降成轻量后处理，推理能力交给在线 RL。

KTO、ORPO、IPO 是同一家族的其他离线目标，损失形式不同。综述见 [arXiv:2503.06072](https://arxiv.org/abs/2503.06072)。本笔记后面的主线是在线策略优化。
