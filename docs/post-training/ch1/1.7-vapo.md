# 1.7 VAPO

论文：*VAPO: Efficient and Reliable Reinforcement Learning for LLM Reasoning with Verifiable Rewards*（ByteDance Seed，[arXiv:2504.05118](https://arxiv.org/abs/2504.05118)）。

GRPO 用整段回答的一个分数代替每个 token 的价值。短回答上这往往够用。长思维链里，答对可能只取决于少数步骤，整段共享优势分不清这些步骤。VAPO 回到 PPO 的价值网络，并把 DAPO 的非对称裁剪、token 级损失和动态采样带过来。优势重新用 GAE 计算，不再用组内标准化。

## 损失

$$
\mathcal{L}(\theta) = \mathcal{L}_{\mathrm{PPO}}(\theta) + \mu \, \mathcal{L}_{\mathrm{NLL}}(\theta), \qquad \mu = 0.1
$$

PPO 项使用 Clip-Higher、token 级归一化和 GAE。正样本项只对当前 batch 里答对的回答做对数似然：

$$
\mathcal{L}_{\mathrm{NLL}}(\theta)
= -\frac{1}{\sum_{o_i \in \mathcal{T}} |o_i|}
\sum_{o_i \in \mathcal{T}}
\sum_{t=1}^{|o_i|}
\log \pi_\theta(a_t \mid s_t)
$$

\(\mathcal{T}\) 是答对的样本。它把已经做对的轨迹再拉高一次似然。论文消融里去掉这一项，AIME 从 60.4 降到 54。

## 价值网络为什么之前不可用

随机初始化的 Critic 在上千 token 的思维链上输出的是噪声。GAE 把噪声当成优势，策略从第一步就走错。VAPO 在 RL 开始前用蒙特卡洛回报预训练 Critic 大约 50 步，让它先见到「整段写完实际拿到多少分」。

从奖励模型初始化 Critic 也会偏。奖励模型主要在结尾打分，对前面的 token 没有可靠的累积回报。价值函数需要的是每个前缀的期望回报，两者不是同一个头。

另外两项把估计和更新拆开：

| 技术 | 做法 | 去掉后的 AIME |
| --- | --- | --- |
| Value Pretraining | RL 前用完整轨迹回报预训练 Critic | 11 |
| Decoupled GAE | Critic 用 \(\lambda=1.0\) 减小偏差；策略更新用 \(\lambda=0.95\) 减小方差 | 33 |
| Length-Adaptive GAE | \(\lambda_{\mathrm{policy}} = 1 - 1/(\alpha \cdot l)\) | 45 |

长度自适应里，\(l\) 是序列长度，\(\alpha\) 是尺度。序列越长，\(\lambda\) 越接近 1，TD 误差看得更远，避免长链被一个过短的折扣截断。

## 消融

| 配置 | AIME 2024 | 相对完整 VAPO |
| --- | --- | --- |
| 完整 VAPO | 60.4 | — |
| 去掉 Value Pretraining | 11 | −49 |
| 去掉 Decoupled GAE | 33 | −27 |
| 去掉 Length-Adaptive GAE | 45 | −15 |
| 去掉 Clip-Higher | 46 | −14 |
| 去掉 Token-Level Loss | 53 | −7 |
| 去掉正样本似然 | 54 | −6 |
| 没有任何这些修复的 PPO | 5 | −55 |

同一设置下 DAPO 的报告分数是 50。价值网络在这份消融里高于去掉 Critic 的 DAPO。DeepSeek-R1 不用 Critic，原因是 671B MoE 上再放一个同规模价值网络的显存，而不是这份 32B 消融被推翻。Seed1.5-Thinking 在约 200B 总参、20B 激活的规模上仍报告价值路线更高，见 [2.6](../ch2/2.6-seed.md)。
