# 1.11 全部算法公式速查表

!!! tip "使用说明"
    本表汇总了第 1 章全部核心策略优化算法的目标形式、优势来源、重要性采样（IS）粒度与信任域控制机制。表中 $r_t, r_{i,t}$ 均为相对采样旧策略 $\pi_{\theta_{\text{old}}}$ 的逐 token 概率比，$s_i$ 为长度归一化的序列几何平均概率比，$\pi_{\text{ref}}$ 为冻结参考策略。完整推导与适用条件请查阅对应小节。

| 算法 | 核心目标 / 损失项（简化表示） | 优势 / 信号来源 | IS 粒度 | 裁剪 / 门控机制 | 典型范式 | 核心解决的痛点 |
|------|------------------------------|----------------|---------|----------------|----------|---------------|
| **[DPO](1.3-dpo.md)** | $-\log \sigma\!\left(\beta \log \frac{\pi_\theta(y_w)}{\pi_{\text{ref}}(y_w)} - \beta \log \frac{\pi_\theta(y_l)}{\pi_{\text{ref}}(y_l)}\right)$ | 离线成对偏好 $(y_w \succ y_l)$ | 无（离线） | $\beta$ 隐式 KL 约束 | 离线 RLHF | 省去独立 RM 训练与在线 Rollout 开销 |
| **[PPO](1.4-ppo.md)** | $\min\!\big(r_t \hat{A}_t,\, \mathrm{clip}(r_t, 1-\varepsilon, 1+\varepsilon)\hat{A}_t\big)$ | GAE + Critic $V_\psi$ | Token | 对称硬裁剪 | 在线 RLHF | 单步策略更新过猛导致崩溃 |
| **[GRPO](1.5-grpo.md)** | $\min\!\big(r_{i,t}\hat{A}_i,\, \mathrm{clip}(r_{i,t})\hat{A}_i\big) - \beta \mathbb{D}_{\text{KL}}$ | Group Relative（组内标准化或去均值） | Token | 对称硬裁剪 | **RLVR** / RLHF | 消除同规模 Critic 显存与价值估计误差 |
| **[DAPO](1.6-dapo.md)** | 全局 Token 平均 $+\;\mathrm{clip}(r_{i,t}, 1-\varepsilon_{\text{low}}, 1+\varepsilon_{\text{high}})\hat{A}_i$（无 KL） | Group Relative + 动态采样过滤 | Token | **非对称**硬裁剪 ($\varepsilon_{\text{high}}>\varepsilon_{\text{low}}$) | **RLVR** | 缓解熵坍塌、全对/全错空转与长链稀释 |
| **[VAPO](1.7-vapo.md)** | DAPO 式 PPO 损失 $+\;\mu \mathcal{L}_{\text{NLL}}(\text{正例})$ | **预训练 Critic** + 解耦/长度自适应 GAE | Token | 非对称硬裁剪 | **RLVR** | 超长 CoT 内部的逐 token 精细信用分配 |
| **[CISPO](1.8-cispo.md)** | $\mathrm{sg}\!\big(\mathrm{clip}(r_{i,t}, 1-\varepsilon_{\text{low}}^{\text{IS}}, 1+\varepsilon_{\text{high}}^{\text{IS}})\big) \hat{A}_i \log \pi_\theta$ | Group Relative + 动态采样 | Token | **裁剪 IS 权重系数**（不丢 $\log\pi$ 梯度） | **RLVR** | 多轮更新中低概率“反思分岔词”梯度归零 |
| **[GSPO](1.9-gspo.md)** | $\min\!\big(s_i \hat{A}_i,\, \mathrm{clip}(s_i, 1-\varepsilon_l, 1+\varepsilon_r)\hat{A}_i\big)$ | Group Relative | **Sequence（几何平均）** | 序列级硬裁剪（$\varepsilon \sim 10^{-4}$） | **RLVR** | **MoE 专家路由跳变导致 Token IS 噪声崩溃** |
| **[SAPO](1.10-sapo.md)** | $\dfrac{4}{\tau_{i,t}}\sigma\!\big(\tau_{i,t}(r_{i,t}-1)\big)\hat{A}_{i,t}$ | Group Relative | Token（温和条件下逼近 Sequence） | **连续 Sigmoid 软门控**（非对称 $\tau$） | **RLVR** | 消除硬裁剪边界梯度跳变，兼顾 MoE 稳定与局部抗噪 |

!!! info "把握全表的三个观察维度"
    1. **优势怎么来（要不要 Critic）**：除 PPO 与 VAPO 采用 Critic + GAE 做 token 级归因外，其余在线算法均沿用 GRPO 的组内相对优势以省去 Critic 显存；
    2. **信任域怎么加（硬裁目标 vs 裁权重 vs 软门控）**：PPO/GRPO/DAPO/GSPO 越界后梯度归零；CISPO 封顶权重但保留 $\log\pi_\theta$ 梯度；SAPO 用 $\mathrm{sech}^2$ 软权重实现处处连续衰减；
    3. **粒度怎么对齐（Token vs Sequence）**：GSPO 率先将比率升至序列几何均值以对齐序列奖励并稳住 MoE，而 SAPO 在 Token 级软门控下实现了向序列级一致性的平滑过渡。
