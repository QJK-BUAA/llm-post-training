# 1.11 公式速查

符号以 [1.2](1.2-rlhf-rlvr.md) 为准。\(r\) 都是相对旧策略 \(\pi_{\theta_{\mathrm{old}}}\) 的比率。优势的具体形式见各节，这里只标来源。

| 算法 | 单步贡献 | 优势 | 比率粒度 | 越界时 |
| --- | --- | --- | --- | --- |
| PPO | \(\min(r_t A_t, \mathrm{clip}(r_t) A_t)\) | GAE + Critic | token | 对称硬平台，梯度为 0 |
| GRPO | 同上，再加 KL | 组内均值，可选再除标准差 | token | 对称硬平台 |
| DAPO | 非对称 clip，按 token 总数归一化，无 KL | 组内相对 | token | 上界更宽，仍会到 0 |
| VAPO | DAPO 式 PPO 项 \(+\ \mu \mathcal{L}_{\mathrm{NLL}}\) | GAE | token | 非对称硬平台 |
| CISPO | \(\mathrm{sg}(\mathrm{clip}(r_t))\, A\, \log\pi_\theta\) | 组内相对 | token | 系数封顶，\(\log\pi\) 仍有梯度 |
| GSPO | \(\min(s_i A_i, \mathrm{clip}(s_i) A_i)\) | 组内相对 | 序列几何平均 | 硬平台，\(\varepsilon\sim 10^{-4}\) |
| SAPO | 软门控 \(f(r)\) 进入目标 | 组内相对 | token，温和条件下接近序列 | 权重连续下降，不在边界置 0 |

读表时的三个限制：

- GRPO 的标准差版本和「只减均值」版本都会出现。V3.2 用的是只减均值。
- CISPO 在优势为 0 时梯度仍是 0。M1 实验只收紧上界。
- SAPO 接近序列级行为需要小步长和较低的组内方差。
