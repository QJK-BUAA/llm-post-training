# 1.6 DAPO

论文：*DAPO: An Open-Source LLM Reinforcement Learning System at Scale*（ByteDance Seed 与清华 AIR，[arXiv:2503.14476](https://arxiv.org/abs/2503.14476)）。全称是 Decoupled Clip and Dynamic Sampling Policy Optimization。

它在 Qwen2.5-32B 基座上把 AIME 2024 的 avg@32 做到 50，高于 DeepSeek-R1-Zero-Qwen-32B 的 47，步数约为后者的一半。对照的是同尺寸的 32B 复现，不是 671B 的 DeepSeek-R1（79.8）。

## 目标

$$
\mathcal{J}_{\mathrm{DAPO}}(\theta)
= \mathbb{E}
\left[
\frac{1}{\sum_{i=1}^{G}|o_i|}
\sum_{i=1}^{G}
\sum_{t=1}^{|o_i|}
\min \Big(
r_{i,t} \hat A_{i,t},\;
\mathrm{clip}(r_{i,t},\, 1-\varepsilon_{\mathrm{low}},\, 1+\varepsilon_{\mathrm{high}})\, \hat A_{i,t}
\Big)
\right]
$$

约束是一组里既有做对的、也有做错的：

$$
0 < \big|\{o_i : \text{核验通过}\}\big| < G
$$

KL 项被去掉。作者的理由是：长思维链要离开初始分布才会出现多步推理，KL 在这里会挡住需要的偏移。

## 四项改动

**非对称裁剪。** 实验取 \(\varepsilon_{\mathrm{low}}=0.2\)，\(\varepsilon_{\mathrm{high}}=0.28\)。上界放宽，低概率 token 的比率可以长得更高再被截住；下界保持，避免概率过快塌掉。越界之后梯度仍会变成 0，只是正优势一侧的平台来得更晚。

**动态采样。** 全对或全错的题优势为 0。DAPO 在采样后丢掉这些题，换成组内有对有错的题，使这一步的 batch 都有方向。论文里它是累计表的最后一项，从 42 分提到 50 分。

**按 token 归一化。** GRPO 先在每条回答内部平均，再对回答平均，每条回答总权重相同。100 个 token 的回答和 10 个 token 的回答各占一份，短回答里每个 token 的权重是长回答的 10 倍。DAPO 改为除以组内 token 总数，每个 token 权重相同，长回答因为 token 更多而贡献更大的总梯度。

论文指出两个后果。优质长回答里的推理 token 在 sample-level 下权重过小，模型学不到。超长回答里的重复和乱码又得不到足够惩罚，长度和熵会一起不健康地上升。Token-level 损失对 AIME 的直接涨分很小，主要改善的是长度增长是否健康。

**超长奖励。** 设缓冲长度 \(L_{\mathrm{cache}}\)。长度还在 \(L_{\max}-L_{\mathrm{cache}}\) 以内时不罚；进入缓冲后线性降到 \(-1\)；超过 \(L_{\max}\) 记 \(-1\)。

$$
R_{\mathrm{length}}(y)=
\begin{cases}
0, & |y| \le L_{\max}-L_{\mathrm{cache}} \\[4pt]
\dfrac{(L_{\max}-L_{\mathrm{cache}})-|y|}{L_{\mathrm{cache}}}, &
L_{\max}-L_{\mathrm{cache}} < |y| \le L_{\max} \\[8pt]
-1, & |y| > L_{\max}
\end{cases}
$$

论文的实验设置是期望长度 16384，缓冲 4096，生成上限 20480。软惩罚让「差一点写完」和「已经超限」分开。

## 消融是累计加上去的

Table 1 的 AIME 2024 avg@32，起点是 Qwen2.5-32B 上的朴素 GRPO：

| 累计加上 | 分数 |
| --- | --- |
| 朴素 GRPO | 30 |
| Overlong Filtering | 36 |
| Clip-Higher | 38 |
| Soft Overlong Punishment | 41 |
| Token-level Loss | 42 |
| Dynamic Sampling，即完整 DAPO | 50 |

Clip-Higher 的 +2 和 Dynamic Sampling 的 +8 都依赖前面已经加上的项，不能理解成从 30 分各自独立加上去。Token-level 是 41 到 42。这些数字只描述这一次 32B 数学实验。
