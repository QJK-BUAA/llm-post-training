# 1.10 SAPO

论文：*Soft Adaptive Policy Optimization*（Qwen Team，[arXiv:2511.20347](https://arxiv.org/abs/2511.20347)）。用于 Qwen3-VL 系列。

PPO、GRPO、DAPO、GSPO 的信任域都是硬平台：比率一过边界，目标对这个比率的梯度变成 0，边界两侧不连续。SAPO 用一条平滑曲线代替平台。梯度随比率离开 1 而变小，不会在某一个点突然消失。

## 门控和梯度权重

平滑门控写成

$$
f_{i,t}(x)
= \sigma\big(\tau_{i,t}(x-1)\big) \cdot \frac{4}{\tau_{i,t}}
$$

\(x\) 是重要性比率，\(\sigma\) 是 sigmoid。温度按优势的符号取值：正优势 \(\tau_{\mathrm{pos}}=1.0\)，负优势 \(\tau_{\mathrm{neg}}=1.05\)。

若目标通过 \(f(r)\) 进入策略梯度，对比率求导得到权重

$$
w = 4p(1-p)
= \mathrm{sech}^{2}\left(\frac{\tau}{2}(r-1)\right)
$$

其中 \(p=\sigma(\tau(r-1))\)。\(r=1\) 时 \(w=1\)。\(r\) 离开 1 之后，权重按 \(\mathrm{sech}^{2}\) 下降，渐近到 0，但不在有限边界上被置成常数。

\(f(r)\) 是放进目标的门控，\(w\) 是它关于比率的导数。速查表里写的是门控后的贡献形式，实现时要和论文的停止梯度约定一起看，不能把 \(f(r)\) 和 \(w\) 当成同一个系数。

## 三种边界

| 算法 | 比率过大时 |
| --- | --- |
| GRPO | token 比率被水平截断，梯度为 0 |
| GSPO | 序列比率被水平截断，梯度为 0，但 \(10^{-4}\) 的宽度使截断很少发生 |
| SAPO | S 形饱和，权重连续下降 |

## 什么条件下它像序列方法

论文在小步长、组内方差低的条件下说明：token 级软门控的效果会接近一个序列级门控。条件不满足时，它仍按 token 调整权重。因此它在这些条件下和 GSPO 的行为接近，并保留 token 级的弹性。不能把它写成无条件包含 GSPO 的超集。

负优势的温度更高，权重掉得更快。原因来自 softmax：降低被采样 token 的 logit，会把概率质量分给词表里其余大约十万个 token，这一步的梯度更散。正优势主要抬高被采样的 token，方向更集中。负方向因此用更保守的温度。

温度目前是手调的。论文没有给出按模型规模或序列长度自动设定 \(\tau\) 的规则。
