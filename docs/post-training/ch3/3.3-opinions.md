# 3.3 判断

这一节保留原综述的问题意识。事实前提已按论文改写的地方，判断也跟着改。它们是阅读之后的推断，不是实验结果。

## 算法还会怎么变

硬阈值在优化里反复让位于处处可导的惩罚。PPO 的平台、DAPO 放宽后的平台、SAPO 的 \(\mathrm{sech}^{2}\) 权重，看起来像同一条路。由此能推断的只是：新的信任域更可能改温度和门控形状，而不是回到更硬的截断。温度怎么随序列长度变化，论文没有给。

价值网络和组内优势的取舍主要看放不放得下 Critic，以及任务有没有长链条需要拆开。32B 上 VAPO 更高。671B 的 MoE 用组内优势，是因为同规模 Critic 的显存。100B 到 200B 这一段没有一份对所有任务适用的分界。轻量 Critic 若只用几个百分点的额外开销换到一部分 token 优势，会直接改变这个取舍，目前还是空白。

## 题和算法，哪一个杠杆更大

Qwen3 用 3995 道边界上的题、170 步，AIME 提高约 15 分。DAPO 在其他技巧都加上之后，换掉没有区分度的题，从 42 到 50。算法从 GRPO 修到 DAPO，在 32B 上是从 30 修到 50，这个跨度并不小。更准确的说法是：算法修的是结构性故障，题目决定这些算法有没有梯度可用。下一步更可能出现在自动生成「刚好不稳定」的新题，而不是再加一种裁剪。

结构性故障修完一次，就会有一次跳跃：CISPO 让越界 token 的对数概率还有梯度，GSPO 让 MoE 的比率不要被路由噪声占满，VAPO 让 Critic 在 RL 开始时就有意义。在这些故障之外继续调 \(\varepsilon\)，收益会小下来。若有人在大 MoE 上把 Critic 的成本降到可接受，那会是另一次跳跃，而不是调参。

## RL 在选择，还是在教

前几百步更像选择。Qwen3 用很少的步数就大幅提高，说明相关行为在基座里已有概率。拒绝采样本身不更新参数，也能涨分。

训练拉长之后会出现选择解释不了的现象。R1-Zero 的自我修正措辞在预训练语料里并不作为目标出现。蒸馏的天花板停在教师，从头 RL 有时能走出教师没写过的轨迹。一个可操作的分界是：拒绝采样还在涨的时候，RL 主要在放大已有行为；拒绝采样饱和之后，继续训练才更可能走出新的推理习惯。小模型先蒸馏再做少量 RL，是因为选择的前提是这些行为已经有非零概率。

## 竞争壁垒在数据，不在公式

PPO 到 SAPO 的公式、veRL 和 TRL 的实现、论文里的超参表，都是公开的。冷启动数据怎么筛、K2 的真实工具库怎么扩、六维奖励的标注规范、阶段之间的数据比例，报告只给结论。DAPO 公开了代码，复现 50 分仍然需要那套 1.7 万道整数答案的题和同样的过滤。资源有限时，值得投入的是蒸馏质量和领域数据，而不是再发明一个裁剪函数。

后训练的账单也在变厚。V3 的后训练是 1 万美元量级，因为教师已经存在。V3.2 把后训练抬到预训练的 10% 以上。M1 单独一个 RL 阶段的租金是 53.47 万美元。这三笔钱覆盖的阶段不同，不能写成同一条曲线上的十分之一。

## 飞轮

V3 用自己做评判，V3.2 用多个专家的 RL 产出作为通用模型的数据，K2 用模拟器生成轨迹，M2.7 声称模型写了大量训练代码。这些都是飞轮的碎片。终局若是模型出题、核验、再训练，RL 算法只是环里的一个部件。M2.7 的比例缺少可复现细节，现在还不能把它当成已经发生的终局。

若只保留一条操作建议：先让每个训练步的题目都有对有错。动态采样不产生新知识，它只是避免把梯度浪费在优势为 0 的组上。这一项在 DAPO 的累计表里是从 42 到 50，比继续放宽一个已经能工作的裁剪上界更值得先检查。
