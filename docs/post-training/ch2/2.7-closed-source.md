# 2.7 闭源模型

OpenAI、Google、Anthropic 没有公开与 R1 或 Qwen3 同等级别的后训练配方。这里只记能在论文里对上的设计。

## OpenAI

o1、o3 和 GPT-5 的强化学习流水线、奖励模型结构都没有公开。两篇安全论文给出了奖励怎么和思维链隔离。

*Deliberative Alignment*（[arXiv:2412.16339](https://arxiv.org/abs/2412.16339)）把安全做成四步：写出规则，在思维链里按规则推理，过滤输出，再监控。模型在思维链中引用具体条款。这段思维链不给奖励模型看，避免打分器学会「只要写出安全推理的样子就给高分」。

GPT-5 的 safe-completions（[arXiv:2508.09224](https://arxiv.org/abs/2508.09224)）把奖励写成乘积 \(r = \text{helpfulness} \times \text{safety}\)。安全性为 0 时，帮助性再高总奖励也是 0。加法形式 \(h + \lambda s\) 做不到这一点。

## Gemini 和 Gemma 不是同一套公开配方

Gemini 2.5 的长报告里，后训练大约只有两段。能确认的是某种奖励模型加 Critic，作者称为 “RL\*F”，以及大约 1024 到 32768 token 的思考预算。算法名字没有给出。

Gemma 3 是另一份开源报告。里面的 BOND（best-of-n 蒸馏）、WARM（奖励模型权重平均）和 WARP（策略权重平均）不能写成 Gemini 的方法。

## Anthropic

公开文献集中在 2022 到 2023 年。Constitutional AI（[arXiv:2212.08073](https://arxiv.org/abs/2212.08073)）让模型按一组原则批评并修改自己的回答，再用这些偏好做强化学习。后面的自我评判、K2 的量表批评，都能看到这个循环。HH-RLHF 是少数写了 PPO 超参数的工业论文。Claude 3.5 和 Claude 4 的后训练方法没有公开。
