# 2.7 闭源模型概览 — OpenAI、Google 与 Anthropic 可考证实践

!!! note "范围说明"
    OpenAI（o1 / o3 / GPT-5）、Google（Gemini 2.5 / 3.0）与 Anthropic（Claude 3.5 / 4）均未完整公开其旗舰模型的底层强化学习优化器公式与核心数据配比。本节仅整理各家在正式发表的专项论文或技术报告中**明确披露、可严格考证**的后训练机制。

---

## OpenAI — 审慎推理安全对齐与乘法奖励结构

虽然 o1 / o3 的核心推理 RL 细节保密，但 OpenAI 发表的两篇安全对齐论文揭示了“带思维链模型的奖励防钻空子（Anti-Reward-Hacking）”设计：

### 1. Deliberative Alignment（审慎对齐，[arXiv:2412.16339](https://arxiv.org/abs/2412.16339)）

传统安全对齐依赖海量人工标注的拒答/合规偏好对，模型只能靠模糊语感猜测边界（导致要么过度拒答良性问题，要么被越狱绕过）。Deliberative Alignment 将人类编写的显式安全规范文本（Safety Specifications）直接教给推理模型：

- **规范感知思维链（Spec-Aware CoT）**：在合成阶段向模型提供安全条例全文，生成在内部 `<think>` 中显式逐条引述规则分析请求性质的轨迹，随后在 **SFT 与 RL 训练时隐去提示词中的规则文本**，迫使模型将安全规范内化进参数记忆，在推理时自发回忆条款做边界推理；
- **内部 CoT 对奖励模型隐藏（CoT Hidden from RM / Judge）**：在 RL 阶段，判分器**只评估最终呈现给用户的外部回答，绝不直接对内部 `<think>` 推理过程打偏好分**——这与 DeepSeek-R1 阶段 4 的做法完全一致，防止模型在思考链里表演“假装守规矩”来骗取奖励模型高分，同时保持内部思考的诚实可审计性。

### 2. Safe-Completions 与乘法安全奖励（[arXiv:2508.09224](https://arxiv.org/abs/2508.09224)）

针对双重用途（Dual-use，如既有科普价值又有潜在风险）的灰色地带提示，GPT-5 安全后训练摒弃了生硬的“全盘拒答或全盘照办”二分法，转而引导模型给出安全范围内的最大化有帮助回答，并在奖励聚合上采用**乘法结构而非线性加权和**：

$$
R_{\text{total}} = R_{\text{helpfulness}} \times R_{\text{safety}} \qquad (\text{对比传统加法 } R_{\text{helpfulness}} + \lambda R_{\text{safety}})
$$

**核心优势**：在线性加法奖励下，只要模型把回答写得极其详尽讨喜（$R_{\text{helpfulness}}$ 极高），就可能抵消掉违规带来的扣分；而在乘法结构下，**一旦触碰安全红线导致 $R_{\text{safety}} = 0$，无论回答多么精彩，总奖励瞬间归零**，从数学结构上封死了“用高帮助性掩盖不安全性”的权衡漏洞。

## Google — Gemini 2.5 的有限披露与开源 Gemma 3 技术栈

在长达 70 余页的 **Gemini 2.5 技术报告**中，涉及后训练的篇幅非常简略，可确认的要点主要有两项：

1. **采用含 Critic 的强化学习框架**：报告提及联合优化动态更新的奖励模型与 Critic 价值估计（统称为面向多源反馈的强化学习），并大力扩展了训练阶段与测试时思考算力；
2. **原生可控 Thinking Budget（思考预算）**：支持在 `1,024` 至 `32,768` tokens 范围内通过 API 精确指定思考上限，使同一模型在延迟敏感与深度推理场景间平滑切换。

!!! warning "严格区分闭源 Gemini 与开源 Gemma 3 的后训练配方"
    Google DeepMind 在开源轻量模型 **Gemma 3 技术报告**（[arXiv:2503.19786](https://arxiv.org/abs/2503.19786)）中详细披露了一套非常精彩的后训练组合拳——包括 **BOND**（Best-of-N Distillation，让策略向虚拟 Best-of-N 分布做在线蒸馏）、**WARM**（Weight Averaged Reward Models，对多个奖励模型做权重平均以增强抗 Hacking 鲁棒性）以及 **WARP**（Weight Averaged Rewarded Policies，在策略空间做球面线性插值合并）。这套配方在中小规模蒸馏与对齐上极具参考价值，但官方从未声明闭源旗舰 Gemini 系列采用了相同的算法栈，引用时不应将两者混同。

## Anthropic — Constitutional AI（宪法 AI）的深远遗产

Anthropic 自 Claude 3 系列起不再发表详尽算法论文，但其在 2022–2023 年奠定的 **Constitutional AI (CAI)**（[arXiv:2212.08073](https://arxiv.org/abs/2212.08073)）与 **HH-RLHF** 已成为今天几乎所有主流后训练流水线的基础构件：

- **自我批评与修订阶段（SL-CAI）**：给定一套人类编写的简短原则（“宪法”），让模型对自己的初始有害回答按原则写出批评意见（Critique）并自行修改（Revision），再对修改后的安全回答做 SFT；
- **AI 偏好反馈强化学习（RLAIF）**：让模型对照原则比较两条候选回答的好坏以替代昂贵的人类标注，训练偏好模型后运行 RL。前文介绍的 DeepSeek-V3 **Self-Rewarding** 与 Kimi K2 **Self-Critique Rubric Rewards**，本质上都是 Constitutional AI 思想在强推理时代的高阶演进。
