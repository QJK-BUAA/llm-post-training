# Agentic RL 调研报告

<p class="byline">四章 16 节 · 用一个贯穿案例讲清多轮交互、信用分配与异步训练</p>

单轮推理 RL 是「读题，一口气写完，判对错」。Agentic RL 是「边做边看环境反馈，做错一步可能污染后面几十步」。这一字之差，带来了四件全新的事：中间步骤没有分数、赢了不知道算哪一步的功劳、一上来全错学不动、多轮异步训练容易崩。

## 全书贯穿案例与符号约定

第 1 章 6 节共用同一个小场景：**电商退货核查助手**。第 1 步查订单，第 2 步查退货政策，第 3 步提交能不能退的结论。每节都回到这三步上算账，背景不变，只换要解决的问题。

符号和后训练报告对齐，并多一条防撞车约定：

| 符号 | 含义 |
| --- | --- |
| \(k=1,\dots,K\) | 第几**轮**交互（Turn） |
| \(t\) | 词元位置（Token） |
| \(h_k\) | 第 \(k\) 轮开始时的历史：用户请求 + 此前所有思考、动作和环境返回 |
| \(z_k, a_k\) | 模型第 \(k\) 轮生成的思考和工具动作，要算梯度 |
| \(\text{obs}_k\) | 环境返回的文本，**不**用 \(o_k\) 表示，避免和后训练篇的输出 \(o_t\) 撞车 |
| \(\text{mask}=1/0\) | 这个词元是否计入策略损失 |

代表论文索引见 [4.1](ch4/4.1-cheatsheet-timeline.md)。引用数字时以原论文为准；综述里常见的机构、会议和相对提升口径，本报告按一手来源校准后才写。
